# Phase 1: design-partner discovery

Status: **in progress**

This directory contains the operating artifacts for Phase 1 of the
[MVP execution plan](../MVP_EXECUTION_PLAN.md#phase-1--customer-discovery-and-paid-pilot-contract-weeks-14).
It records customer evidence without treating a target account, conversation,
or unsigned proposal as traction.

## Working documents

- [Design-partner playbook](DESIGN_PARTNER_PLAYBOOK.md): target hypothesis,
  interview motion, workflow-observation method, and qualification rubric.
- [Campaign register](CAMPAIGN_REGISTER.md): 30 interview slots, ten workflow
  observations, and weekly funnel totals.
- [Outreach templates](OUTREACH_TEMPLATES.md): warm, direct, observation, and
  paid-pilot messages grounded in a concrete workflow.
- [Workflow record](WORKFLOW_RECORD_TEMPLATE.md): one evidence-complete record
  per observed recurring review.
- [Pilot scorecard](PILOT_SCORECARD_TEMPLATE.md): baseline and frozen success
  thresholds for the selected workflow.
- [Paid-pilot SOW](PAID_PILOT_SOW_TEMPLATE.md): fixed-scope commercial and
  delivery terms for counsel and customer review.
- [Data-flow and security review](DATA_FLOW_SECURITY_REVIEW_TEMPLATE.md): the
  mandatory gate before receiving credentials or customer data.
- [Phase 1 backlog](PHASE_1_BACKLOG.md): ordered work, dependencies, evidence,
  and exit-gate status.

Customer names, personal contact details, credentials, proprietary samples, and
security-sensitive architecture must not be committed to this public
repository. Use approved private systems for live customer records; store only
sanitized IDs and aggregate evidence here.
